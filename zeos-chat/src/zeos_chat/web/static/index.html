ZEOS Chat

Demonstration of a chatbot built as a descriptor tree: a few small text files, one per behaviour, which the ZEOS kernel runs as programs. converse is the resident conversation blocking on read, costing nothing until you type. Speak while it is answering and an interrupt preempts the conversation at a token boundary, between one word and the next; stop fires at high priority to take the machine off whatever it's doing. The model is a device on a pipe, so the kernel keeps running while it thinks. The conversation itself lives in a context window, and the pager evicts the coldest part to a stub if it gets too long. Press Email and a vector dispatches a separate job whose single actuator write is the only effect that leaves the machine — and so the only one the kernel can refuse, on authority or on integrity if that job has read something untrusted. On the right is the kernel's journal: what it did, not what was said.

    The conversation is parked on read stdin; — it runs no forward passes until you say something.
